# 不听课 v1.1.0 使用与升级

这次更新增加可检查的逐字稿中间层、数学与表格导出、课程记忆，并修复配置和重跑时的数据保护问题。

## 升级

先在旧版设置中导出一份备份，结束正在运行的任务，然后更新源代码或解压新包。保留原有 `data/`，重新运行同名启动脚本即可。启动器现在根据依赖文件的内容检测变化：已有虚拟环境也会安装新增依赖，失败后下次启动可重试。

Word 导出使用 `pypandoc_binary==1.17`，首次升级会额外下载约几十 MB 的转换组件；不需要另装完整 LaTeX 环境。公式脚本、字体及 Markdown 组件随应用提供，浏览器预览可以离线工作。

v1.0 的课堂、课程、复习指导和备份可继续读取。新结果保存在独立版本目录，成功后才切换；失败或取消保留之前的指导。结果区的版本选择器可以打开、下载历史稿。备份会包含这些新数据，恢复时只恢复学习数据与非连接设置，保留本机的大模型/语音端点及密钥。

## 逐字稿

1. 导入录音后点 **仅转录**，无需大模型即可生成和导出原始稿。
2. 配好本地或云端大模型，点 **筛选逐字稿**；生成指导时默认也会做这一步，可在设置中关闭。
3. 在 **原文 / 净化稿 / 已剔除** 视图检查结果。相关问答、考试提醒和更正应保留；误删内容可恢复，修订只影响净化稿。
4. **导出当前稿** 下载 Markdown；**导出标注 JSON** 下载完整句段、时间精度、分类和修订。原始转录不会因筛选或修订而覆盖。

筛选需要大模型，使用云端模型会发送相应逐字稿；使用本机 Ollama 等服务可在本地完成。无法确认是否相关的内容默认保留。不同录音中的本地时间与课堂合并时间都会保留；估算时间戳会显示“估算”。

## 复习指导与公式

生成内容增加公式、条件说明和对照表，区分教师原话与需要核对的 AI 概括。页码链接可打开原页；必要图默认全篇最多三张并去重，上限可以在设置中调整。减少配图不会删除来源页码。

网页支持常用 LaTeX 数学、Markdown 表格和图片。Word 使用原生数学节点与表格，公式可以编辑。无法渲染或无法导出的公式会明确报错或显示原文待核对，不能用“能渲染”代替数学正确性。

**扫描件和图片公式**：在设置中填写支持图片输入的“视觉模型”，与当前大模型接口和凭证共用。在课堂的公式页码框填写课件全局页码，如 `2,5`，点 **识别选中公式页**。每次最多六页；所选页会发送给该模型，支持兼容协议的本地视觉端点也可使用。转写结果显示在页面上并标为待核对，下一次生成会使用这些页面证据。

尚未配置视觉模型时，普通文本分析仍可使用；公式图片中无法读取的内容需要对照原页，系统不会自动安装 OCR。识别结果及复习稿的正确性仍需结合原材料检查。

## 外链图片与离线导出

外链图片默认显示加载按钮，点击才会连接来源站点。需要离线保存时，点 **缓存用于离线导出**，再点 **重新导出**；只重新排版，不重新调用语音识别或内容分析。缓存限制公网 HTTPS、图片体积和像素数量，拒绝本机/内网地址和不安全类型。未缓存的外部图片在 Word 中显示说明，不由转换器自动下载。

纯本地使用时不要加载外链或选择云端视觉模型。加载外链时即使不发送 Referrer，图片站点仍可能看到网络地址。

## 课程记忆

课程页可批量选择讲义和录音，先核对每个文件对应的课堂名称：同名归为一堂，不同名称分别新建。确认后逐组导入，不自动开始付费分析；失败时显示完成组数并保留已收到的文件，便于补齐。每次最多五十个文件。

把课堂归入同一课程，使用 **调整课次** 指定授课顺序。生成时默认检索该课程前面的有出处知识、公式和已核对教师强调，不把历史内容冒充本课原话。

课程页可启用/停用记忆、保存自己的术语和符号约定、查看来源。源课堂修订、删除或移动后，下一次检索从当前数据重建；每份指导记录实际使用的历史快照。若要用后续课更正前课，在旧课堂勾选 **允许参考后续课的更正** 再生成。

首版使用本地词项检索，相关性不等同于语义正确性；不同说法仍保留来源，需核对冲突。记忆只在同课程内使用，用户笔记单独标注。

## 错误与自动化调用

某个分析块失败时不发布缺块指导。重试会复用已经完成且输入未变化的分析块；音频未变化时也会复用识别结果。Word 导出失败可点 **重新导出**，之前成功的版本不受影响。

设置中可调整模型输入预算（字符估算）和输出上限。课堂显示已提取材料量；服务接口报告 tokens 时展示其用量，未报告则只显示调用尝试数，不推算或冒充实际费用。

运行期间会禁止删除、改动当前课堂和恢复备份。备份要在任务结束后进行；恢复前检查解压规模与可用空间，失败回滚。

两个应用的写接口现在要求实例令牌。浏览器自动处理；脚本须先请求 `GET /api/security`，再在写请求中携带 `X-CSRF-Token`。仅允许本机 Host 与同源 Origin，服务重启后需获取新令牌。配置接口仅返回是否保存过凭证，修改服务地址后需要重新填写密钥。

## 验证范围

本次提供模拟模型的完整功能回归、原生 Word 数学/表格检查、真实浏览器交互、原有离线与发布包检查。清洗准确率、视觉模型识别效果和跨课记忆的教学质量，仍需用经授权的真实课程数据评估；不把这些模拟检查视为已达到固定准确率。
